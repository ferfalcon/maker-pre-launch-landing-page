# Stage 4 — Define Testable Behavior

Turn approved requirements/design intent into precise observable behavior and acceptance criteria.

## Profile targets

- Express: `WORKPACK.md` → Specification and acceptance criteria.
- Lite: `IMPLEMENTATION-BRIEF.md` → Specification.
- Standard, Full: `SPEC.md`.

Use `SPEC-BEH-*`, `SPEC-INT-*`, `SPEC-ACC-*`, `SPEC-VAL-*`, `SPEC-DATA-*`, and `AC-*` as applicable. Define states, edge cases, responsive/accessibility behavior and failure/recovery behavior without inventing unsupported rules.

Perform two reviews, ensure required acceptance criteria are testable, then run stage preflight.
