# Stage 1 — Audit Pinned Design Evidence

Verify active design snapshots, select the matching source adapter from the actual source, and inspect the complete agreed scope.

## Profile targets

- Express: update `WORKPACK.md` observed design evidence/audit findings.
- Lite, Standard, Full: update `DESIGN-AUDIT.md`.

Inventory applicable screens/flows/viewports/components/variants/styles/variables/assets/content/interactions/states/responsive transformations/accessibility implications/inconsistencies/missing evidence. Use `EVD-*` and `AUD-*` IDs with precise `SRC-DS-*` source regions.

Do not convert observations into product requirements or implementation decisions. Keep Observed/Inferred/Recommended/Confirmed/Open question distinct.

Perform two reviews and run stage preflight before proposing closure.
