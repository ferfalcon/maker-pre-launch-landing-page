# Stage 5 — Review Documentation Consistency

Challenge Stages 1–4 after first-pass corrections. Find contradictions, missing coverage, unsupported behavior, responsive/accessibility gaps, source drift, duplicate ownership, and assumptions presented as facts.

## Profile targets

- Express: record both review passes in `WORKPACK.md`.
- Lite: record both review passes/readiness in `IMPLEMENTATION-BRIEF.md`.
- Standard, Full: update `DOCUMENT-REVIEW.md` and affected owning artifacts.

Correct the owning artifact rather than documenting a contradiction as acceptable debt. Re-run checks after corrections. Then run stage preflight.
