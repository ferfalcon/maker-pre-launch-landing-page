# Standard Site Example

This directory contains examples for a multi-page site or substantial interface feature using the Standard profile.

A complete Standard example should contain separate artifacts for:

```text
SOURCE-BASELINE.md
PROJECT-CONTEXT.md
WORKFLOW-STATE.md
DESIGN-AUDIT.md
REQUIREMENTS.md
DESIGN.md
SPEC.md
DOCUMENT-REVIEW.md
PLAN.md
PLAN-REVIEW.md
TASKS-INDEX.md
Phase-##--Task-##.md
IMPLEMENTATION-REVIEW.md
```

`ARCHITECTURE.md` remains conditional. The included component architecture example demonstrates how to document a meaningful reusable interaction boundary without adopting a full application architecture.

All example technologies, names, states, and patterns are non-normative.
