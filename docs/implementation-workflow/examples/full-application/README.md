# Full Application Example

This directory contains examples for full-stack applications or projects with authentication, persistence, complex integrations, multiple services, migrations, or significant operational risk.

A Full example uses the complete Standard artifact set plus:

- `ARCHITECTURE.md`;
- architecture decision records when needed;
- explicit persistence, authentication, security, deployment, rollback, reliability, observability, and testing decisions.

The included full-stack architecture example is non-normative. Its frameworks, hosting providers, authentication model, data model, and directory structure must not be copied without repository and project evidence.
